# Antenna Measurement Application

## Description

This repository contains the source code of an antenna measurement application developed in MATLAB. The application provides a graphical user interface for controlling the measurement process and interacting with the antenna measurement system.

## Requirements

* MATLAB
* MATLAB App Designer

## Running the Application

To start the application, open MATLAB and run:

```matlab
app_robot_control.mlapp
```

Alternatively, open the file in MATLAB App Designer and click **Run**.

## Main Entry Point

The main application file is:

```text
app_robot_control.mlapp
```

This file launches the graphical user interface and initializes the application.

## Notes

Make sure that all required project files and robot files are properly configured before running the application.
